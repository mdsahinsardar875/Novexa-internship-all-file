Endpoint Reference

GET/api/tasksGet all tasks — supports ?status= and ?priority= filters
GET/api/tasks/:idGet a single task by id
POST/api/tasksCreate a new task from a JSON body
PUT/api/tasks/:idUpdate an existing task
DELETE/api/tasks/:idDelete a task
Try: GET /api/tasks/2 → single task  |  POST /api/tasks with a body → adds a card  |  PUT /api/tasks/1 body {"status":"done"} → moves the card  |  DELETE /api/tasks/1 → removes it
